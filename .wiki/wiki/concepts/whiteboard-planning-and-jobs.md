# Whiteboard Planning And Jobs

> Whiteboard work can be handled asynchronously. The backend acknowledges quickly, queues a job, plans typed board operations, applies them to board state, and lets the browser poll until the board update is complete.

## Command Layer

`lib/whiteboardCommandService.js` turns high-level commands into normalized command objects. It supports creating artifacts, modifying items, moving items, connecting items, grouping items, reorganizing artifacts, emphasizing items, deleting items, and replacing artifacts.

The command service also resolves targets by id, selected item, recent item, text, group title, and semantic fallback. Destructive commands require explicit permission and high target confidence before producing operations.

## Planner Layer

`lib/whiteboardPlannerService.js` builds model input that includes artifact type, board strategy, visual summary goal, session context, current board snapshot, supported operation types, and layout constraints. The planner expects strict JSON and validates returned operations.

When the planner model is unavailable or returns invalid operations, deterministic fallback layouts produce valid operation batches for idea maps, process flows, architecture maps, comparison maps, and action plans.

## Job Layer

`lib/whiteboardJobService.js` stores jobs on the session state. A job moves through queued, planning, applying, completed, failed, or needs-clarification states. Completed jobs include applied board operations, an undo checkpoint id, and the resulting board snapshot.

The server exposes this through `POST /board/commands` and `GET /board/jobs`, while `POST /tools/execute` can also return a `whiteboard_job` when realtime tool calls queue board work.

## Frontend Polling

`public/app.js` tracks pending job ids, starts polling every 900 ms, and stops when no pending jobs remain. Completed jobs re-render the board and append a system summary. Failed or clarification-needed jobs append an explanatory system line.

This gives the voice interaction a fast acknowledgement while keeping more expensive visual planning off the critical audio path.
